Instruções de Formato
Clientes
  • nome: obrigatório, máximo 120 caracteres
  • contato: opcional, máximo 120 caracteres
  • email: opcional, máximo 120 caracteres
Caçambas
  • codigo: obrigatório, máximo 10 caracteres, único
  • capacidadeM3: obrigatório, número inteiro > 0
Contratos
  • cliente_nome: nome do cliente existente
  • cacamba_codigo: código da caçamba existente
  • endereco: endereço do aluguel
  • data_inicio: formato YYYY-MM-DD
  • data_fim: formato YYYY-MM-DD
  • valor_contrato: formato 0.00
  • valor_troca: formato 0.00
  • numero_trocas: número inteiro ≥ 0
